# リレー道場（保護継電器 訓練ゲーム）

**遊ぶ：https://lutelute.github.io/relay-dojo/**

保護継電器の判定を身につけ、事故のあとを預かる、訓練用の教材ゲームです。単元（14）で学び、当直（9 夜）では、事故のあとの警報から事故点を読み、開閉器を入り切りして復旧します。答えも、開閉器を動かした結果も、「[保護継電器 動作シミュレータ](https://lutelute.github.io/protection-relay-sim/)」と同じ計算が出します。ブラウザで開くだけで動きます（1 枚の HTML、ライブラリなし）。

このリポジトリには、遊ぶページ（`index.html`）だけを置いています。いまは試しの版です。

## 注意

整定値・動作時間は教材用の代表例です。実機の整定は保護協調計算で決めてください。継電器は瞬時復帰、波形は概念図です。復旧の時間は目安で、事故の種類・設備・事業者で違います。当直の作業の時間はゲームの数字で、実際の復旧の手順ではありません。
